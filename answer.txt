JavaScript Basics — 50 Answers

Variables

1. What is a variable in JavaScript?
Answer:
A variable is a container used to store a value.

2. What are the three keywords used to create variables?
Answer:
var, let, and const.

3. Write the syntax to create a variable using var.
Answer:
var variableName = value;

Example:
var age = 25;

4. Write the syntax to create a variable using let.
Answer:
let variableName = value;

Example:
let age = 25;

5. Write the syntax to create a variable using const.
Answer:
const variableName = value;

Example:
const age = 25;

6. What is declaration?
Answer:
Declaration means creating a variable without assigning a value.

Example:
let age;

7. What is initialization?
Answer:
Initialization means assigning a value to a variable when it is created.

Example:
let age = 25;

8. What is reassignment?
Answer:
Reassignment means changing the value of an existing variable.

Example:
let age = 25;
age = 30;

9. What is redeclaration?
Answer:
Redeclaration means declaring the same variable again using the same keyword.

Example:
var age = 25;
var age = 30;

10. Which keyword allows redeclaration?
Answer:
var allows redeclaration.

11. Which keyword allows reassignment?
Answer:
var and let allow reassignment.

12. Which keyword requires initialization when declared?
Answer:
const requires initialization when declared.

13. Identify the declaration and initialization:

let age = 25;

Answer:
Declaration: let age
Initialization: 25

const

36. Create a const variable called pi with the value 3.14.

Answer:
const pi = 3.14;

37. Can a const variable be reassigned?
Answer:
No, a const variable cannot be reassigned.

38. Can a const variable be redeclared?
Answer:
No, a const variable cannot be redeclared.

39. What is wrong with this code?

const age;
age = 25;

Answer:
A const variable must be initialized when it is declared.
The code causes an error.

Correct code:
const age = 25;

40. What happens here?

const price = 500;
price = 1000;

Answer:
It causes an error because a const variable cannot be reassigned.

41. Create a const variable called country with the value "India".

Answer:
const country = "India";

42. What will be the output?

const x = 100;
console.log(x);

Answer:
100

43. Which keyword should you use if the value should not be reassigned?
Answer:
const

44. What is the difference between let and const?
Answer:
let can be reassigned, but const cannot be reassigned.

Example:

let age = 25;
age = 30;

const pi = 3.14;
// pi = 4;  This causes an error.

45. What is the difference between var and const?
Answer:
var can be reassigned and redeclared.
const cannot be reassigned or redeclared.


Printing & Console

46. Write JavaScript code to print Hello World using console.log().

Answer:
console.log("Hello World");

47. Write JavaScript code to print the number 500 using console.log().

Answer:
console.log(500);

48. What is the purpose of console.warn()?

Answer:
console.warn() is used to display a warning message in the console.

Example:
console.warn("This is a warning");

49. What is the purpose of console.error()?

Answer:
console.error() is used to display an error message in the console.

Example:
console.error("Something went wrong");

50. What is the purpose of each?

alert()
prompt()
confirm()
document.writeln()
console.log()

Answer:

alert()
Used to display a message to the user.

Example:
alert("Hello");

prompt()
Used to ask the user to enter a value.

Example:
prompt("Enter your name:");

confirm()
Used to ask the user for confirmation.

Example:
confirm("Are you sure?");

document.writeln()
Used to write content directly to the web page.

Example:
document.writeln("Hello World");

console.log()
Used to display information in the browser console.

Example:
console.log("Hello World");
